Record Book — Device Setup & Data Export

This admin page does two jobs: connect this computer to the school's sync service (one-time, per computer), and export everything this computer holds so the migration can include it. It changes nothing about how the other pages work until the migration is sealed.

2 · Sync service connection (one-time, per computer)

The sync service is the school's single gatekeeper for saving data (see the deployment guide that came with the migration tools). Paste its web address and the shared secret that was set when it was deployed. Both are stored only on this computer — never in the code, never published, never inside an export file. Enter them once on each machine the school uses.

Setting up the sync service for the first time? Press the button, copy the generated value into the sync service's HMAC_SECRET setting, keep an offline copy somewhere safe, then paste the same value into the secret box above. It is generated on this computer and shown only here.

3 · Export this computer's local data

Some records may exist only on this computer and in no backup. This button gathers everything CESTIS holds on this computer into one file you download and give to the person running the migration (drop it in the migration folder — the tool recognises it by name). Do this once on every computer the school uses. Sign-in tokens and session state are deliberately left out, and the shared secret cannot appear in it.
