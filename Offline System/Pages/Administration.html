System Settings

Classes and meetings run in the built-in conference room; a Large Class runs on the video server named below.

Before a class can start, the two browsers have to be introduced to each other, and that is done by a video server. Left blank, the Centre uses a free public one — which means every class, staff meeting and all-staff conference stops if that public service is busy or unreachable. Name the Centre's own video server here and it is tried first, with the public one kept as a fallback. Accepts host, host:port or a full address.

Some networks — many phones on mobile data — cannot be reached directly, and a call to them only connects through a relay server. There is no longer a free public one, so without a relay of the Centre's own those calls fail (the room says so when it happens). One per line: turn:host:port username password (or turns:). A free, self-hosted coturn relay server is enough. Stored with the Centre's settings, never in the published code.

A Large Class runs on a Jitsi video server. Left blank it uses the free public meet.jit.si, which no longer supports meetings embedded in another site: it can ask the host to sign in and end the meeting after a few minutes. Name the Centre's own Jitsi video server here (an https:// address).

Mixed into each Large Class room's password, so a room cannot be entered by someone who only guesses its address. Change it only between classes: every device must hold the same phrase.

If a system shows a blank panel on a device
Both HEART/NSTA systems serve a security certificate browsers do not recognise (NET::ERR_CERT_AUTHORITY_INVALID). A browser will not show that certificate warning inside a panel, so the panel stays blank until the certificate is approved once, on that device, in a normal tab.

Every page has a Page blank? button with the steps, and those steps appear automatically the first time a device opens each system. Each person has to do it once per device and browser — it does not carry over.

The permanent fix is on HEART/NSTA's side: a certificate from a public certificate authority for those hostnames. Until then, Embedded works fine after the one-time approval; switch a system to Launch panel if you would rather it always open in its own window.
