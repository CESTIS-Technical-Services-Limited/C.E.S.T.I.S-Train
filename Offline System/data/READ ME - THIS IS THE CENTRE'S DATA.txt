================================================================================
  THIS FOLDER IS THE CENTRE'S RECORDS.
================================================================================

Every part of the system saves here and reads from here:

    the LMS dashboard ............ CESTIS_LMS_Dashboard.json
    Student Progress ............. CESTIS_Student_Progress.json
    Transcript / Grades .......... CESTIS_Transcript_Grades.json
    Certificate/Transcript Reqs .. CESTIS_Transcript_Requests.json
    School Fee Management ........ CESTIS_School_Fees.json
    Cashbook ..................... CESTIS_Cashbook.json
    Payment Vouchers ............. CESTIS_Payment_Vouchers.json
    Payments / Invoices .......... CESTIS_Payments_Invoices.json
    Invoice ...................... CESTIS_Finance_Invoices.json
    Quotation .................... CESTIS_Finance_Quotes.json
    Purchase Order ............... CESTIS_Finance_PurchaseOrders.json
    Virement Requests ............ CESTIS_Virement_Requests.json
    Staff Payslips ............... CESTIS_Staff_Payslips.json
    Staff Time Clock ............. CESTIS_Staff_TimeClock.json

The files appear as each part is used for the first time. An empty folder is
normal on day one.

--------------------------------------------------------------------------------
BACKING UP
--------------------------------------------------------------------------------
Copy this whole "data" folder onto a memory stick. That is a complete backup of
the Centre's trainees, fees, grades and financial records.

To restore, put the folder back in the same place and start the system again.

Do it on a schedule somebody is responsible for. This folder living on one
computer is the single thing that would be hard to recreate.

--------------------------------------------------------------------------------
WHAT NOT TO DO
--------------------------------------------------------------------------------
Do not edit these files by hand while the system is running — the next save
will overwrite your changes. Stop the server first if you must.

Do not delete a file to "start fresh" for one part of the system unless you
mean to lose that part's records permanently.

--------------------------------------------------------------------------------
THE SAME FILES AS THE ONLINE VERSION
--------------------------------------------------------------------------------
These are the same files, in the same format, that the online version keeps in
Google Drive. A folder copied off this machine can be read by the online system
and the other way round.
