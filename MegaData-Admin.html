MegaData — Device Setup & Data Export

This admin page does two jobs: connect this computer to the school's data broker (one-time, per device), and export everything stored locally in this browser so the migration can include it. It changes nothing about how the other pages work until the migration is sealed.

2 · Broker connection (one-time, per device)

The broker is the school's single gatekeeper for saving data — a small Google Apps Script running in the school's own Google account (see megadata/broker-appsscript/README-DEPLOY.md). Paste its web address and the shared secret that was set when it was deployed. Both are stored only on this computer — never in the code, never on GitHub, never inside an export file. Enter them once on each machine the school uses.

Setting up the broker for the first time? Press the button, copy the generated value into the Apps Script HMAC_SECRET Script Property, keep an offline copy somewhere safe, then paste the same value into the secret box above. It is generated on this computer and shown only here.

3 · Export this computer's local data

Some records may exist only in this browser's storage and in no Drive backup. This button gathers everything CESTIS has stored locally into one file you download and give to the person running the migration (drop it in the migration folder — the tool recognises it by name). Do this once on every computer the school uses. Sign-in tokens and session state are deliberately left out, and the broker secret cannot appear in it.
